# 作业 3 第二部分 · W9 预习：我希望助手拥有的两个工具

W8 的助手只会"查资料 + 说话"，检索时机是写死的（`use_rag=True` 就一定先检索）。W9 要让它自己决定"这问要不要查、查什么"。下面两个工具是我这周实际缺的能力。

## 工具 1：查生词表 `lookup_word`

**解决什么**：现在助手答"这个词几级"只能靠语义检索，`data/生词表.csv` 里明明有精确答案，却常常检索不到（W7 的检索命中里就混进过 `生词表.csv` 第 1 段，答的却不是那一行）。这是"精确查表"的活，不该交给向量相似度。

| 项 | 内容 |
|---|---|
| 输入 | `word`（字符串，必填，如 `"把"`）；`level`（可选，1–6，只在同名多级时过滤） |
| 输出 | JSON：`{"word": "把", "pinyin": "bǎ", "level": 2, "pos": "介词", "example": "我把书放在桌子上。", "found": true}`；查不到时 `{"found": false, "word": "把"}`，由模型转述成"生词表里没有这个词" |
| 数据来源 | `weekpath.data_path("生词表.csv")`，只读，不写 |
| 失败情形 | 文件缺失 → 返回 `{"error": "生词表不可用"}`，不让异常冒到对话层 |

## 工具 2：算词汇覆盖率 `coverage`

**解决什么**：备课时常要判断"这段课文对 HSK4 学生难不难"。这件事模型算不准（W7 实验里 1.5b 把 `1000/3245` 算成除法），但代码算得准——典型的"该交给工具"的场景。

| 项 | 内容 |
|---|---|
| 输入 | `text`（字符串，要分析的课文/句子）；`level`（整数，默认 4，用哪一级的词汇表做基准） |
| 输出 | JSON：`{"total": 86, "known": 71, "unknown": 15, "rate": 0.826, "unknown_words": ["焉", "叟", "智"]}`，`rate` 保留三位小数 |
| 实现 | 按字/词切分后与 `生词表.csv` 中 `level <= 4` 的词条求差集；中文分词用简单的最长匹配即可，不引第三方库 |
| 失败情形 | `text` 为空 → `{"error": "text 为空"}`；`level` 不在 1–6 → `{"error": "level 需在 1–6"}` |

## 为什么是这两个

两个工具刚好覆盖 W9 要讲的两种调用动机：`lookup_word` 是"我知道该查什么，只是不想让模型猜"（参数确定、单次调用）；`coverage` 是"这一步模型算不了，必须外包给代码"（模型负责组织语言，工具负责给数）。有了它们，`use_rag` 那个布尔开关才会变成"模型自己决定调不调"。
