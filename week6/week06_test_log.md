## 反思：什么任务固定本地、什么固定云端（约 200 字）

固定走本地的是**碰得到学生个人信息**的活：作文批改、成绩评语、错题分析。这类任务一旦出机器就是
数据事故，答案差一点可以人工兜；本机组 1、组 2 也证明了本地确实能出活，只是要人复核。

固定走云端的是**要知识准确度、要多步推理**的活：语法点讲解、45 分钟教案、长文改写。W5 的对比里
1.5b 把"把字句"讲成被动句，云端四点全对，这个差距不是调参数能补的。

课堂演示固定本地：断网也能跑，且`prefer="local"`本身自带云端兜底，等于"本地优先 + 云端保险"。

拿不准时默认 `prefer="local"`——它是唯一一个**两边都试过**的选项。

## 附录｜可移植性自测（作品集仓库里只有 week6/ 一个目录）

作品集仓库里没有根目录的 `weekpath.py`，所以 `llm.py` 的 import 做成了两段式：
有 `weekpath` 就用它（跨周导入），没有就退回"只加载本目录的 .env"。

```text
测试条件：独立目录（无 weekpath）
[耗时/费用] 实际引擎=local 模型=qwen2.5:0.5b 用时 14.17s 输出 30 tokens 费用 0.000000 元
是否回退：否
```

把 `week6/` 单独拷到一个空目录、不带 `.env` 也能跑（模型回落默认值 `qwen2.5:0.5b`）。
这一条不是讲义要求，但不做的话，老师克隆仓库后 `python test_paths.py` 会直接
`ModuleNotFoundError: weekpath`。

## prefer 选型表（W5 选型的代码化）

| 教学任务 | prefer | 理由 |
|---|---|---|
| 批改学生作文 / 写成绩评语 | `"local"` | 未成年人数据不出本机，隐私红线优先于答案质量 |
| 批量生成格式固定、可人工校验的练习 | `"local"` | 高频调用不计费，小模型够用，出错能一眼看出来 |
| 复杂教案设计 / 多步推理 / 长文改写 | `"api"` | 质量差距明显，值得花 token |
| 教室断网 / 平台限流时的课堂演示 | `"local"` | 离线可用是硬约束，且失败会自动切云端 |
| 拿不准时的默认 | `"local"` | 本地优先 = 自带云端兜底 |
