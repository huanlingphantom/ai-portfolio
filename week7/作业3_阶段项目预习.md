目标：把 `llm.py`（统一入口、双向回退）和 `rag_qa.py`（检索增强）组装成一个**能演示、能发布**的问答助手，
考核 15%（Release 发布 + 互评）。

## 一、目录结构（建议）

```
学科问答助手/
├── README.md                  ← 安装三步 + 截图 + 已知限制
├── requirements.txt
├── .env.example               ← 只写键名，不写值
├── weekpath.py                ← 沿用：路径 + 跨周 import + 加载 .env
├── data/
│   ├── 等级标准节选.txt         ← 主语料（W7 已用）
│   └── 愚公移山.txt            ← 第二份语料，用来证明"换文件就能换知识库"
├── engine/
│   ├── __init__.py
│   ├── llm.py                 ← 从 week06 搬，改成 engine 包内相对 import
│   └── rag.py                 ← 从 week07 rag_qa.py 拆：只留 load/split/embed/retrieve，去掉 CLI
├── app/
│   ├── cli.py                 ← 命令行：单问 / 交互 / --prefer --k
│   └── web.py                 ← 可选：streamlit 单页（一个输入框 + 一个回答区 + 展开"参考资料"）
├── scripts/
│   ├── build_index.py         ← 建库 / 重建 / 清库
│   └── eval.py                ← w7_check.py 升级版：跑 N 组，出对照表 md
├── tests/
│   └── test_smoke.py          ← 三条冒烟：Ollama 在 / 库能建 / rag_qa 有返回
└── docs/
    ├── 幻觉对照表.md            ← W7 的成果，扩到 10 组
    └── 路演脚本.md              ← 5 分钟演示流程（含一个故意失败的例子）
```

**为什么要拆 `engine/` 和 `app/`**：现在 `rag_qa.py` 里"检索逻辑"和"命令行打印"混在一个文件里，
W8 要加网页界面时就得复制粘贴。拆开之后 `app/cli.py` 和 `app/web.py` 共用同一套 `engine`，
这也是 W6 把 `llm.ask()` 抽成统一入口的同一个理由。

## 二、要补齐的功能（按优先级）

### P0 必须补（不做就不算 v1.0）

| 功能 | 现状 | 怎么补 |
|---|---|---|
| 引用落地校验 | 模型可以标 `[9]` 这种不存在的序号 | `rag_qa()` 里正则抽 `\[(\d+)\]`，超出 `1..k` 的判"引用失效"，在答案后追加"⚠️ 引用失效，请核对原文" |
| 拒答阈值 | top-1 距离 1.04 时也照样喂给模型（第 4 组就翻车） | `if chunks[0].dist > 0.85: return "资料里没有直接相关的内容"`，不进生成 |
| 多语料入库 | 只认 `等级标准节选.txt` 一个文件 | `data/*.txt` 全量 load，每块 metadata 记 `source` 文件名，出处写成"文件·章节" |
| 安装说明 | 依赖散落在注释里 | `requirements.txt` + README 三步（拉嵌入模型 → 装依赖 → 跑一条） |
| 异常兜底 | Ollama 没起时报 `ConnectionError` 堆栈 | 捕获后给人话：「本地模型没启动，先开 Ollama；或加 `--prefer api`」 |

### P1 演示加分项

- **多轮追问**：把最近 2 轮 `Q/A` 拼进 prompt（注意别把旧答案当资料，容易串）；
- **网页界面**：streamlit 一个输入框，回答下面可展开"参考资料 [1][2][3]"，距离一起显示——**互评时这个最抓分**；
- **换知识库演示**：同一个问题对两份语料各答一次，证明"RAG 的知识来自文件，不是来自模型"。

### P2 有余力再做

- 增量建库：改了一个 txt 只重建这个文件的块（用 `source` 字段过滤后删除）；
- 表格保护分块：把"表头 + 说明 + 数据行"锁成一块（W7 的 500 字切法会把表切开）；
- 答案缓存：同一问题 + 同一库直接返回上次结果，省演示时的等待。

## 三、路演怎么讲（5 分钟）

1. **痛点**（30 秒）：问裸模型"HSK4 多少词"，它答 1000 或 1200，都很自信——放 `hallucination_log.md` 的截图。
2. **做法**（1 分钟）：四步图 + 一句"检索负责找，llm.ask 负责说，出处负责让人能核"。
3. **现场跑**（2 分钟）：一个答对带出处的、一个"资料里没有"的（拒答阈值生效）、一个故意失败的。
4. **边界**（1 分钟）：1.5b 读不了表、云端能读；所以 `prefer` 不是"性能开关"，是"要不要把数据发出去"的开关。
5. **下一步**（30 秒）：W9 工具调用、W10 MCP 打算接什么。
