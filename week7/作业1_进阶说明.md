## 2. 进阶（二选一）：我选「给每段记来源 + 答案附出处」

### 怎么做的

**① 来源本身就在分块里。** 建库时 `_add_heading_context()` 已经给每块补了一行
`【三、各等次总体描述】` 这样的抬头——它就是天然的"出处"，不用额外维护一张映射表。

**② 拼上下文时给每段编号**（`retrieve()`）：

```
[1]（出处：三、各等次总体描述）
完成中等阶段的学习，应掌握音节 908 个（新增 300）、汉字 1800 个（新增 900）…
[2]（出处：四、三维评价维度）
…
```

**③ 提示词里要求回标**（`build_prompt()`）：

```python
return ("根据以下资料回答问题，资料中没有的内容就如实说“资料中未提及”。\n"
        "回答完在末尾用一行写“出处：[序号]”，序号对应资料里的 [1][2][3]。\n"
        "%s\n\n问题：%s" % (ctx, question))
```

**④ 终端把 `[n]` 翻回人话**（`__main__` 里回答完再打印一遍）：

```
--- 引用来源（模型标的 [n] 对应这里）---
[1] 二、三等九级与 HSK 的对应关系（距离 0.6116）
[2] 四、三维评价维度（距离 0.9886）
[3] 一、语言量化指标总表（音节 / 汉字 / 词汇 / 语法）（距离 1.0394）
```

多了一步"翻译"，是因为模型只会写 `[3]`，而读者要看到"一、语言量化指标总表"才知道它引的是哪一节。

### 效果（同一个问题、同一批检索结果，只换生成模型）

**云端（`--prefer api`，deepseek-chat）—— 会标出处，还会解释口径：**

> 根据资料 [3] 的"语言量化指标总表"，四级（中等）的词汇量一栏为"1000/3245"，其中 1000 为四级新增词汇量，
> 3245 为累计词汇量。因此 HSK4 需要掌握的新增词汇为 1000 个，累计词汇为 3245 个。
>
> 出处：[3]

**本地 1.5b —— 答对了数，但不标出处：**

> HSK 4 需要掌握的词汇数量为 1000/3245。

### 这一步的真实价值

- **出处让"答对"变成"可复核"。** 同一个 3245，标了 `[3]` 就能一眼翻到总表核对；不标就只能信它。
- **出处也暴露了"检索不准"。** 第 4 组（见 `hallucination_log.md`）首段是"二、HSK 对应关系"（没有数字），
  模型却引了 `[3]`——说明它其实是靠第 3 段答的。**没有出处这层，这种"检索排序很差但答案侥幸对"的情况根本看不出来**。
- **小模型的短板也暴露了**：1.5b 完全无视"写一行出处"的指令（试了 3 次都没写），
  云端 5/5 都写了。这类"格式服从"能力，比答对一个数字更能区分模型档位。

### 已知不足

- 出处只到"节"（如"一、语言量化指标总表"），没到"第几段第几行"——因为语料本身没有段落编号。
  要更细，得在分块时把 `start_index` 也带进元数据，生成 `第 1 节·第 3 块` 这样的标识。
- 模型标的 `[n]` 没有做**落地校验**：理论上它可能标一个不存在的 `[9]`。下一步应该在 `rag_qa()` 里
  用正则抽出所有 `[n]`，凡不在 `1..k` 的就判为"引用失效"，并把该条答案降级标注。
