## 2. 生成环节复用了 llm.ask()

```python
def rag_qa(question, prefer="local", k=3, rebuild=False):
    from llm import LLM          # week06 的模块，靠 weekpath 才能 import 到
    llm = LLM()
    ctx = retrieve(question, k=k, rebuild=rebuild)
    return llm.ask(build_prompt(question, ctx), prefer=prefer)
```

没有新写一套 `requests.post(... /chat/completions)`。证据是运行日志里那行 `[耗时/费用]`——
**它是 `week06_双引擎/llm.py` 自己打的**，说明请求确实从那里出去：


## 3. 幻觉对照表

`hallucination_log.md`，5 组，每组四列（问题 / 裸答 / RAG 答含引用片段 / 差距与原因）。
一句话结果：**裸答 0/5 正确；RAG 3/5 完全答对，2/5 照样翻车（一次把 1000/3245 做成了除法）。**

| # | 问题 | 裸答 | RAG 答 | 判定 |
|---|---|---|---|---|
| 1 | 中等阶段·词语 | 5000–10000 | **5456** | ✅ |
| 2 | 中等阶段·语法点 | 100–150 | **424** | ✅ |
| 3 | 中等阶段·音节 | 500–1000 | **908** | ✅ |
| 4 | HSK4 词汇量 | 1000 | 1000/3245 = 3.104 | ❌ |
| 5 | 高等阶段·汉字 | 约 5000 | 1200（新增当总量） | ❌ |

前 3 组就是"差距肉眼可见"的那三组：裸答给的全是区间，RAG 给的是精确值。
后 2 组如实写进了表里——**没把它改成"RAG 全对"**，因为 1.5b 读不了 7 列数字表这件事本身就是要记的结论。

## 4. 检索相关性（不是随便 top-k）

`python week07_RAG/rag_qa.py "问题" --show` 打印每段距离（余弦距离，越小越像）：

| 问题 | top-1 距离 | top-1 是哪一段 | 可靠性 |
|---|---|---|---|
| 中等阶段·词语 | 0.6462 | 三、各等次总体描述（原文就有 5456） | 好 |
| 中等阶段·语法点 | 0.6118 | 一、语言量化指标总表（数字在散文段，排第 2） | 好 |
| 中等阶段·音节 | 0.6462 | 三、各等次总体描述 | 好 |
| HSK4 词汇量 | 0.6116 | **二、HSK 对应关系（一个数字都没有）** | 差 |
| 高等阶段·汉字 | 0.6576 | 二、HSK 对应关系（总表掉到 0.7681） | 差 |

后两行就是第 4、5 组翻车的直接原因：**首段不相关，模型却不肯说"没找到"，而是拿别处的数字硬凑。**
（第 4 组那个 3.104 就是它把 `1000/3245` 当除法算出来的。）

**改前 / 改后（本周唯一动过检索的地方）**：

给每块前面补一行「它属于哪一节」（`_add_heading_context()`）之前，问"HSK4 需要掌握多少词汇"，
总表只排第 3（0.495），首段是"三等九级与 HSK 的对应关系"（0.701）——一堆"HSK 四至六级"、没有数字。
补抬头之后同类问题总表能升到第 1（0.681）。但抬头也救不了所有问法：问成"四级（中等）本级新增词汇量是多少"，
总表仍被"四、三维评价维度"压住（那段说"应掌握音节、汉字、词汇的数量"，语义最像却没有数字）。
**结论：检索质量是 语料 × 分块 × 问法 三件事一起决定的。**

## 5. 提示词

```python
def build_prompt(question, ctx):
    return ("根据以下资料回答问题，资料中没有的内容就如实说“资料中未提及”：\n"
            "%s\n\n问题：%s" % (ctx, question))
```

和讲义片段 3 一字不差。这句限定语在调参期确实触发过：问"一级要求掌握多少个音节"、
top-3 恰好没覆盖到"一级"那行时，模型答的是"资料中没有提及一级的要求"——没资料时它选择不编。
（那一次是调试期的组，没进最终五组。）

顺带一个反例：第 4 组首段根本没数字，它却答 `1000/3245 = 3.104`——**说明"未提及"这句能挡住"没资料"，
挡不住"资料不对口"**。
