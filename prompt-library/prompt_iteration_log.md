# 提示词迭代实录 (Prompt Iteration Log)

## 迭代对象：教案扩展模板.md

### 第 1 轮（初始版）
**提示词**：帮我把“把”字句扩展成一份教案。
**输出结果**：AI 给了一份教案，但结构松散，只有“导入、讲解、练习、总结”四个大标题，没有时间分配，也没有具体的教学活动描述。
**诊断**：任务描述过于笼统，AI 不知道需要多少个环节、每个环节多长时间、面向什么水平的学生。
**改了什么**：加入【角色】“资深对外汉语教研员，擅长设计45分钟标准课”，并在【任务】中明确要求“含导入、讲解、操练、产出”四个环节。
**好在哪里**：教案结构清晰了，四个环节完整，但时间分配仍然模糊，课堂可操作性不强。

### 第 2 轮（增加时间与受众约束）
**提示词**：在原有基础上，增加【要求】“受众为零基础/初级留学生，环节须包含时间分配，用 Markdown 表格输出”。
**输出结果**：AI 输出了 Markdown 表格，每个环节都标注了时间，受众也调整为零基础水平。
**诊断**：格式已经规范，但“操练”环节设计得太笼统，只有一句“学生练习”，没有区分机械操练、半机械操练和交际操练。
**改了什么**：增加【示例】（Few-shot），贴入一个标准教案表格，展示“教学环节 + 时间 + 教学活动 + 设计意图”的完整结构，并在操练环节中示范如何分层设计。
**好在哪里**：AI 照着示例生成，操练环节被拆成了三个梯度，课堂活动具体可执行，时间分配也合理了。

### 第 3 轮（增加 Few-shot 示例后）
**提示词**：加入标准教案表格示例，并强调“操练环节必须包含机械、半机械、交际三个梯度”。
**输出结果**：完美输出。导入自然、讲解清晰、操练分层、产出真实，时间分配精确到分钟，表格格式统一。
**对比**：三轮迭代后，从“结构松散、无法直接上课”到“环节完整、时间精确、操练分层、可直接进课堂”，提示词的约束力显著提升。
**结论**：对于教案类任务，Few-shot（示例）和【要求】中的分层约束缺一不可，它们共同决定了输出内容的课堂可用性。
