# 教案扩展模板
## 提示词
**【角色】** 你是资深对外汉语教研员，擅长设计45分钟标准课。
**【任务】** 将下列核心教学点扩展为完整的45分钟教案（含导入、讲解、操练、产出）。
**【要求】** 受众为零基础/初级留学生，环节须包含时间分配，用Markdown输出。
**【示例】** 
以下是标准输出格式，请严格照此结构生成：
| 教学环节 | 时间 | 教学活动 | 设计意图 |
| :--- | :--- | :--- | :--- |
| 导入 | 5分钟 | 教师做动作引入，问学生“老师做了什么？”，引出本课语法点。 | 用真实动作降低认知门槛。 |
【待粘贴区】：[“把”字句]
## 适用说明
适合新手教师备课、公开课设计。换课型改哪里？修改【要求】里的环节和受众水平。
## 最佳示例
### 教学点：“把”字句
**教学对象**：初级留学生（HSK2-3）
**课时**：45分钟

| 教学环节 | 时间 | 教学活动 | 设计意图 |
| :--- | :--- | :--- | :--- |
| 导入 | 5分钟 | 教师做动作：关门、开窗、拿书。问学生：“老师做了什么？”引导学生说出“老师关门了”。 | 用真实动作引入，降低认知门槛。 |
| 讲解 | 10分钟 | 板书公式：S + 把 + O + V + 其他成分。举例：“我把书放在桌子上。”强调“把”后宾语是已知的、被处置的对象。 | 公式化教学，直观易懂。 |
| 操练 | 15分钟 | **机械操练**：看图说话（把苹果吃了/把门关上）。<br>**半机械操练**：完成句子（我把作业____）。<br>**交际操练**：两人一组，一人指令，一人执行并描述。 | 从控制到半控制，逐步内化语法规则。 |
| 产出 | 10分钟 | 学生用“把”字句描述自己房间的三样东西，如“我把书放在书架上”。 | 在真实语境中运用语法。 |
| 总结与作业 | 5分钟 | 复习公式，布置作业：用“把”字句写3个关于你房间的句子。 | 巩固课堂所学。 |
