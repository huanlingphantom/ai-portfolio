# 课堂活动模板
## 提示词
**【角色】** 你是课堂活动策划师，擅长游戏化教学。
**【任务】** 根据下列语言点，设计一个15分钟的课堂互动活动。
**【要求】** 面向中小学生，需要明确道具、规则、分组方式，输出为Markdown表格。
**【示例】** 
以下是标准输出格式，请严格照此结构生成：
| 环节 | 规则 | 分组方式 |
| :--- | :--- | :--- |
| 热身 | 教师展示图片提问，引导学生说出目标句型。 | 全班齐答 |
| 竞赛 | 分组抢答造句，答对得1分。 | 分为A、B两组 |
【待粘贴区】：[比较句（A比B+形容词）]
## 适用说明
适合活跃课堂气氛、公开课亮点设计。换场景改哪里？修改【要求】里的受众年龄段。
## 最佳示例
| 环节 | 规则 | 分组方式 |
| :--- | :--- | :--- |
| 热身 | 教师展示图片（大象和蚂蚁），提问：“谁大？”引导学生说出“大象比蚂蚁大”。 | 全班齐答 |
| 竞赛 | 分两组，每组派代表抽两张图片，必须在5秒内说出一个比较句，说得对得1分。 | 分为A、B两组 |
| 升级 | 增加难度，要求用“A比B+形容词+数量词”造句（如：西瓜比苹果大两倍）。 | 小组讨论后抢答 |
| 总结 | 得分高的小组获得“比较王”称号，教师带读所有生成的句子。 | 全班 |
