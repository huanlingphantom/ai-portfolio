## 最佳示例
**一、公式化讲解**
- 公式：**V + 着 + (O)**
- 意义：表示动作或状态的**持续**。
- 例句：他坐着。/ 门开着。/ 他拿着一本书。

**二、阶梯式练习**

| 层级 | 练习形式 | 示例 |
| :--- | :--- | :--- |
| 机械练习 | 看图造句 | 图：一个人站着。→ 学生说：“他站着。” |
| 半机械练习 | 完成句子 | 门____（开），里面没人。→ 学生填：“开着” |
| 交际练习 | 情境问答 | 教师问：“你一般怎么坐？” 学生答：“我坐着听课。” |

**三、课后作业**
- 用“着”描述你房间里的三样东西。
